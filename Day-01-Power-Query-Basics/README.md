# 📊 Day 01 – Power Query Basics

## 📖 Overview
On Day 1, I learned the fundamentals of **Power Query** in Power BI. Power Query is used to clean, transform, and prepare data before building reports and dashboards.

---

## 🎯 Objective
- Import Excel data into Power BI.
- Explore the Power Query Editor.
- Perform basic data transformations.
- Understand how **Applied Steps** work.

---

## 🛠️ Tools Used
- Power BI Desktop
- Power Query Editor
- Microsoft Excel

---

## 📂 Dataset
**File:** `Sales_Data.xlsx`

### Dataset Columns

- Customer
- City

- Quantity
- Price

## 📚 Topics Covered

### ✅ Import Data
- Imported an Excel dataset into Power BI.

### ✅ Power Query Editor
- Opened the dataset using **Transform Data**.

### ✅ Rename Column
- Renamed **Price** to **Unit Price**.

### ✅ Custom Column
Created a new column:


## 💡 Key Concepts Learned
